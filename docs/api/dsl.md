The unified Domain-Specific Language (DSL) suite for `nim-esphome`. Re-exports declarative macros and runtime engines for Home Assistant controls, voice satellite state machines, Lovelace dashboard surfaces, custom actions, non-blocking RTOS task schedules, and composite hardware surfaces.
