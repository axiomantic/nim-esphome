Module: nim_esphome/entities¶

First-class Home Assistant entity bindings for numerical sensors, binary sensors, switches, and text sensors.

entities ¶

nim_esphome/entities: Type-safe bindings for ESPHome entities.

Allows Nim embedded code to interact directly with ESPHome components: - Sensor: Numerical floating-point sensor entities. - BinarySensor: Boolean digital sensor entities (e.g. motion, door contacts). - Switch: Boolean controllable switch entities (e.g. relays, toggles). - TextSensor: String/text status sensor entities. - Select[T]: Type-safe selection/dropdown entities (enums or strings). - Number: Bounded numerical sliders/inputs. - Button: Action trigger buttons.

State updates published via publishState are forwarded to Home Assistant. Inbound state changes from Home Assistant trigger registered onState / onPress callbacks.
